## 🎮 ภาพรวมของโปรเจกต์ Project Overview
แอปพลิเคชันเกมทายคำศัพท์ภาษาอังกฤษที่พัฒนาขึ้นด้วย **Python** และเฟรมเวิร์ก **Kivy** โดยนำเสนอในธีมของ **Scooby-Doo** ที่ต้องหนีผี ผู้เล่นจะได้รับคำศัพท์ภาษาไทยและต้องพิมพ์คำแปลภาษาอังกฤษให้ถูกต้องภายในเวลาที่กำหนด 16 วินาที ก่อนที่ผีจะเดินมาถึงตัว Scooby 

ตัวเกมผสมผสานกลไกการพิมพ์ เข้ากับระบบการบริหารจัดการทรัพยากร คะแนน/พลังชีวิต และความกดดันจากเวลาและเหตุการณ์สุ่ม ทำให้การท่องจำคำศัพท์มีความท้าทายและสนุกสนานมากยิ่งขึ้น

### 🌟 ฟีเจอร์หลักของเกม Core Features
* **หมวดหมู่และระดับความยาก:** มีหมวดหมู่ให้เลือก ได้แก่ Animals & Nature, Daily Life และ Science & IT โดยแบ่งความยากออกเป็น 5 ด่าน
* **ระบบเวลาและตัวละครผี Time & Ghost System:** ผีจะขยับเข้าใกล้ผู้เล่นเรื่อยๆ ตามเวลาที่ลดลง หากเวลาหมด ผู้เล่นจะเสียพลังชีวิต 1 หน่วย (Scooby Snacks)
* **ระบบคอมโบและโบนัส Combo & Fever System:** * ตอบถูกติดกัน 3 ครั้ง ได้รับคะแนน x2
  * ตอบถูกติดกัน 5 ครั้ง ได้รับคะแนน x3 พร้อมเอฟเฟกต์หน้าจอ Fever
* **ระบบร้านค้าทักษะ Skill Shop:** ผู้เล่นสามารถนำคะแนนที่สะสมไว้มากดซื้อตัวช่วยระหว่างเล่นได้
  * **Heal (50 Pt):** ฟื้นฟูพลังชีวิต 1 หน่วย
  * **Hint (20 Pt):** ใบ้ตัวอักษร 1-3 ตัวแรกของคำศัพท์ ขึ้นอยู่กับความยาวของคำ
  * **Reset Ghost (30 Pt):** ดึงผีกลับไปที่จุดเริ่มต้น, เพิ่มเวลา 5 วินาที และลดความเร็วของเวลาลงชั่วคราว
* **เหตุการณ์สุ่มสุดหลอน Spooky Events:** ระหว่างเล่นมีโอกาส 20% ที่จะเกิดเหตุการณ์รบกวนผู้เล่น
  * `Thunder`: เสียงฟ้าร้องพร้อมหน้าจอสั่นและกระพริบ
  * `Poltergeist`: ตัวหนังสือและช่องพิมพ์คำศัพท์จะกระพริบไปมา
  * `Jump Scare`: มีคำขู่ปรากฏขึ้นกลางหน้าจอพร้อมเสียงตกใจ

## 💻 อธิบายการทำงานของโค้ดเชิงลึก (Deep Dive into the Code)

โปรเจกต์นี้ถูกออกแบบโดยใช้สถาปัตยกรรมการแบ่งไฟล์เป็นสัดส่วน เพื่อแยกส่วน UI, Logic และ Asset ออกจากกัน:

### 1. `main.py` ระบบจัดการหลักและหน้าจอ UI
ไฟล์นี้เป็นหัวใจสำคัญของแอปพลิเคชัน ประกอบไปด้วย:
* **Screen Management:** ใช้ `ScreenManager` ของ Kivy ในการสลับหน้าจอระหว่าง `MainMenuScreen`, `OptionsScreen`, `GameStartMenuScreen` และ `GameScreen`
* **MainLayout:** คลาสควบคุมหน้าจอเกมหลัก ทำหน้าที่:
  * โหลดข้อมูลคำศัพท์จากไฟล์ `vocab_data.json` ด้วยฟังก์ชัน `load_vocabulary()`
  * จัดการลูปเวลาผ่าน `Clock.schedule_interval` (`update_timer`) ที่ประมวลผล 60 เฟรมต่อวินาที เพื่อให้ผีเดินอย่างนุ่มนวล
  * ตรวจจับการพิมพ์ของผู้เล่น (Event Binding) ผ่านฟังก์ชัน `on_text_change()` และตรวจคำตอบด้วย `check_answer()`
  * สร้างแอนิเมชันต่างๆ (Floating Text, Screen Shake, ตัวละครขยับ) โดยใช้ `Animation` ของ Kivy
* **การบันทึกสถิติ:** มีฟังก์ชัน `save_highscore()` และ `update_highscore()` ที่อ่าน/เขียนข้อมูลคะแนนสูงสุดลงไฟล์ `highscore.json`

### 2. `systems/game_logic.py` ระบบตรรกะและการคิดคำนวณ
ดูแลการคำนวณผลลัพธ์โดยไม่ต้องยุ่งกับ UI:
* **`check_answer(user_answer, correct_word)`:** ตรวจสอบความถูกต้องของคำศัพท์ โดยแปลงเป็นตัวพิมพ์เล็กและตัดช่องว่าง หากถูกจะบวกคะแนน (10 * คอมโบ) หากผิดจะรีเซ็ตคอมโบ
* **`update_combo()`:** เช็คค่า Streak หรือการตอบถูกต่อเนื่อง เพื่อปรับ `combo_multiplier`
* **`buy_life()`, `get_hint()`:** ฟังก์ชันจัดการการหักคะแนนและคืนค่าตัวช่วยต่างๆ ให้กับ `main.py`

### 3. `widgets/ghost.py` การจัดการออบเจกต์ศัตรู
คลาส `Ghost` ที่สืบทอดมาจาก `Image`:
* **`sync_position(current_time, max_time)`:** เป็นฟังก์ชันที่คำนวณตำแหน่ง X ของรูปภาพผี โดยแปลงเวลาที่เหลือให้เป็นเปอร์เซ็นต์ (Progress) แล้วจับคู่กับพิกัดบนหน้าจอ เพื่อให้ผีเคลื่อนที่เข้าหา Scooby แบบเรียลไทม์
* **`reset()`:** ดึงผีกลับไปยังจุดเกิด (`start_x`) นอกหน้าจอ

### 4. `systems/vocabgame.kv` และ KV String ใน `main.py` การออกแบบ UI
* ใช้ **KV Language** ในการจัดวาง Layout เช่น `FloatLayout` และ `BoxLayout`
* มีการสร้าง Custom Widget เช่น `SmoothButton` ปุ่มมุมโค้งแบบกำหนดค่าได้ และ `CardBox` กล่องพื้นหลังกึ่งโปร่งใส เพื่อความสวยงาม
* การวาดกราฟิกบน Canvas (`canvas.before`, `canvas.after`) สำหรับการแสดงสีพื้นหลังและเอฟเฟกต์สีหน้าจอกระพริบ
